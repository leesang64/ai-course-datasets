# 4.13 데이터 사전과 입력 검증

이 값은 배포한 고정 CSV에서 직접 계산했다. 최소·최대는 이 파일의 관측 범위이며 모델의 허용 범위나 모집단의 한계가 아니다. 결측 수는 NaN 기준이다.

## churn.csv

1200행. 전체 열 기준 완전 중복 0행. 난수 시드 20261016의 완전한 교육용 합성 고객 데이터. 실제 고객 자료를 복사·익명화한 것이 아니며 개인과 연결되지 않음.

- `customer_id`: 합성 행 식별자. 모델 입력에서 제외. object; 결측 0개; 고유값 1200개; 범주 예: SYN00000, SYN00001, SYN00002, SYN00003.
- `age`: 생성한 가상 나이. int64; 결측 0개; 고유값 63개; 범위 18~80, 평균 48.9675.
- `tenure`: 생성한 가상 이용 기간. int64; 결측 0개; 고유값 72개; 범위 1~72, 평균 36.6917.
- `monthly_charge`: 생성한 가상 월요금. float64; 결측 20개; 고유값 1165개; 범위 15~134.843, 평균 68.3516.
- `total_charge`: 월요금×기간에 잡음을 더한 가상 누적 요금. float64; 결측 20개; 고유값 1180개; 범위 21.5875~9101.15, 평균 2522.15.
- `contract`: 가상 계약 범주. object; 결측 0개; 고유값 3개; 범주 예: monthly, two_year, one_year.
- `internet`: 가상 인터넷 서비스 범주. object; 결측 0개; 고유값 3개; 범주 예: dsl, fiber, none.
- `support`: 가상 지원 여부. object; 결측 20개; 고유값 2개; 범주 예: no, yes.
- `ebilling`: 가상 전자 청구 여부. object; 결측 0개; 고유값 2개; 범주 예: yes, no.
- `churn`: 생성 확률로 표집한 가상 이탈 정답 0/1. int64; 결측 0개; 고유값 2개; 범위 0~1, 평균 0.195833.

## 재실행 전 검사

1. 열 이름과 순서, 목표 열의 제외 여부를 확인한다.
2. 결측을 학습 입력과 정답에서 구분한다. 목표 결측을 입력 결측처럼 대치하지 않는다.
3. CSV를 수정했다면 기존 SHA-256과 결과는 재현 기준으로 더 이상 일치하지 않는다.
4. 관측 범위 밖 수치를 즉시 잘못된 값으로 삭제하지 말고, 정의·수집 조건·모델 입력 범위를 확인한다.
5. 전처리 통계와 모델 선택은 훈련·검증 범위에서 수행하고 최종 평가 자료를 분리한다.

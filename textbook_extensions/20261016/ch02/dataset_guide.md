# 2.13 데이터 사전과 입력 검증

이 값은 배포한 고정 CSV에서 직접 계산했다. 최소·최대는 이 파일의 관측 범위이며 모델의 허용 범위나 모집단의 한계가 아니다. 결측 수는 NaN 기준이다.

## linear.csv

90행. 전체 열 기준 완전 중복 0행. 난수 시드 42로 만든 교육용 합성 데이터. 실제 측정값 아님.

- `x`: 무차원 독립 입력. float64; 결측 0개; 고유값 90개; 범위 -3~3, 평균 5.42776e-17.
- `y`: 생성식으로 만든 연속형 목표. float64; 결측 0개; 고유값 90개; 범위 -5.48278~6.39025, 평균 0.706278.

## 재실행 전 검사

1. 열 이름과 순서, 목표 열의 제외 여부를 확인한다.
2. 결측을 학습 입력과 정답에서 구분한다. 목표 결측을 입력 결측처럼 대치하지 않는다.
3. CSV를 수정했다면 기존 SHA-256과 결과는 재현 기준으로 더 이상 일치하지 않는다.
4. 관측 범위 밖 수치를 즉시 잘못된 값으로 삭제하지 말고, 정의·수집 조건·모델 입력 범위를 확인한다.
5. 전처리 통계와 모델 선택은 훈련·검증 범위에서 수행하고 최종 평가 자료를 분리한다.

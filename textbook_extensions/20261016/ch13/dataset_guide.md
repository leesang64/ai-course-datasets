# 13.13 데이터 사전과 입력 검증

이 값은 배포한 고정 CSV에서 직접 계산했다. 최소·최대는 이 파일의 관측 범위이며 모델의 허용 범위나 모집단의 한계가 아니다. 결측 수는 NaN 기준이다.

## drift.csv

500행. 전체 열 기준 완전 중복 0행. 시드 42의 교육용 합성 분포 이동. 실서비스 데이터 아님.

- `reference`: 기준 정규분포에서 생성한 가상 관측. float64; 결측 0개; 고유값 500개; 범위 -3.64841~3.17885, 평균 -0.00760867.
- `current`: 평균·분산을 바꾸어 생성한 가상 관측. float64; 결측 0개; 고유값 500개; 범위 -2.74896~4.00138, 평균 0.581598.
## serving.csv

360행. 전체 열 기준 완전 중복 0행. 시드 42의 교육용 합성 회귀. 실제 운영 성능을 의미하지 않음.

- `x0`: 합성 회귀의 첫째 입력. float64; 결측 0개; 고유값 360개; 범위 -2.91716~2.80957, 평균 -0.0871204.
- `x1`: 합성 회귀의 둘째 입력. float64; 결측 0개; 고유값 360개; 범위 -2.43638~2.81265, 평균 -0.0164053.
- `x2`: 합성 회귀의 셋째 입력. float64; 결측 0개; 고유값 360개; 범위 -3.06378~2.85744, 평균 -0.0053271.
- `target`: 합성 두 반달 정답 0/1. float64; 결측 0개; 고유값 360개; 범위 -8.39247~6.82076, 평균 -0.151606.

## 재실행 전 검사

1. 열 이름과 순서, 목표 열의 제외 여부를 확인한다.
2. 결측을 학습 입력과 정답에서 구분한다. 목표 결측을 입력 결측처럼 대치하지 않는다.
3. CSV를 수정했다면 기존 SHA-256과 결과는 재현 기준으로 더 이상 일치하지 않는다.
4. 관측 범위 밖 수치를 즉시 잘못된 값으로 삭제하지 말고, 정의·수집 조건·모델 입력 범위를 확인한다.
5. 전처리 통계와 모델 선택은 훈련·검증 범위에서 수행하고 최종 평가 자료를 분리한다.

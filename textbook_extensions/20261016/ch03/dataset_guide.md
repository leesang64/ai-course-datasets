# 3.13 데이터 사전과 입력 검증

이 값은 배포한 고정 CSV에서 직접 계산했다. 최소·최대는 이 파일의 관측 범위이며 모델의 허용 범위나 모집단의 한계가 아니다. 결측 수는 NaN 기준이다.

## maze.csv

6행. 전체 열 기준 완전 중복 1행. 저자가 정의한 6×6 교육용 격자. 실제 지도 아님.

- `c0`: 격자의 0번째 열. 값 0은 통로, 1은 장애물. int64; 결측 0개; 고유값 2개; 범위 0~1, 평균 0.333333.
- `c1`: 격자의 1번째 열. 값 0은 통로, 1은 장애물. int64; 결측 0개; 고유값 2개; 범위 0~1, 평균 0.5.
- `c2`: 격자의 2번째 열. 값 0은 통로, 1은 장애물. int64; 결측 0개; 고유값 2개; 범위 0~1, 평균 0.166667.
- `c3`: 격자의 3번째 열. 값 0은 통로, 1은 장애물. int64; 결측 0개; 고유값 2개; 범위 0~1, 평균 0.666667.
- `c4`: 격자의 4번째 열. 값 0은 통로, 1은 장애물. int64; 결측 0개; 고유값 2개; 범위 0~1, 평균 0.333333.
- `c5`: 격자의 5번째 열. 값 0은 통로, 1은 장애물. int64; 결측 0개; 고유값 2개; 범위 0~1, 평균 0.166667.
## items.csv

8행. 전체 열 기준 완전 중복 0행. 교육용 8개 배낭 물품을 명시적으로 정의. 실제 상품 가격 아님.

- `item`: 가상 물품 이름. object; 결측 0개; 고유값 8개; 범주 예: A, B, C, D.
- `weight`: 가상 중량. int64; 결측 0개; 고유값 6개; 범위 2~7, 평균 4.
- `value`: 가상 효용. int64; 결측 0개; 고유값 8개; 범위 5~16, 평균 9.625.

## 재실행 전 검사

1. 열 이름과 순서, 목표 열의 제외 여부를 확인한다.
2. 결측을 학습 입력과 정답에서 구분한다. 목표 결측을 입력 결측처럼 대치하지 않는다.
3. CSV를 수정했다면 기존 SHA-256과 결과는 재현 기준으로 더 이상 일치하지 않는다.
4. 관측 범위 밖 수치를 즉시 잘못된 값으로 삭제하지 말고, 정의·수집 조건·모델 입력 범위를 확인한다.
5. 전처리 통계와 모델 선택은 훈련·검증 범위에서 수행하고 최종 평가 자료를 분리한다.

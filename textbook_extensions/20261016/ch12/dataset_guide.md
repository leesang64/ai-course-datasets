# 12.13 데이터 사전과 입력 검증

이 값은 배포한 고정 CSV에서 직접 계산했다. 최소·최대는 이 파일의 관측 범위이며 모델의 허용 범위나 모집단의 한계가 아니다. 결측 수는 NaN 기준이다.

## queries.csv

3행. 전체 열 기준 완전 중복 0행. 직접 정의한 교육용 Q 행렬. 학습된 언어 임베딩 아님.

- `d0`: 직접 정의한 벡터의 첫 성분. int64; 결측 0개; 고유값 2개; 범위 0~1, 평균 0.666667.
- `d1`: 직접 정의한 벡터의 둘째 성분. int64; 결측 0개; 고유값 2개; 범위 0~1, 평균 0.666667.
## keys.csv

4행. 전체 열 기준 완전 중복 0행. 직접 정의한 교육용 K 행렬. 학습된 언어 임베딩 아님.

- `d0`: 직접 정의한 벡터의 첫 성분. int64; 결측 0개; 고유값 2개; 범위 0~1, 평균 0.5.
- `d1`: 직접 정의한 벡터의 둘째 성분. int64; 결측 0개; 고유값 3개; 범위 -1~1, 평균 0.25.
## documents.csv

60행. 전체 열 기준 완전 중복 0행. 기존 GitHub 12_Sequence_Transformer_GenerativeAI/course_documents.csv.

- `id`: 교육용 검색 문서 식별자. object; 결측 0개; 고유값 60개; 범주 예: DOC000, DOC001, DOC002, DOC003.
- `title`: 교육용 문서 제목. object; 결측 0개; 고유값 60개; 범주 예: 인공지능 교재 문서 0, 인공지능 교재 문서 1, 인공지능 교재 문서 2, 인공지능 교재 문서 3.
- `content`: 검색 대상으로 제공한 교육용 본문. object; 결측 0개; 고유값 13개; 범주 예: 이 문서는 인공지능 학습 주제 1장에 대한 핵심 개념, 실습 절차, 평가 방법을 설명한다. 데이터 누수 방지와 재현성을 강조한다., 이 문서는 인공지능 학습 주제 2장에 대한 핵심 개념, 실습 절차, 평가 방법을 설명한다. 데이터 누수 방지와 재현성을 강조한다., 이 문서는 인공지능 학습 주제 3장에 대한 핵심 개념, 실습 절차, 평가 방법을 설명한다. 데이터 누수 방지와 재현성을 강조한다., 이 문서는 인공지능 학습 주제 4장에 대한 핵심 개념, 실습 절차, 평가 방법을 설명한다. 데이터 누수 방지와 재현성을 강조한다..

## 재실행 전 검사

1. 열 이름과 순서, 목표 열의 제외 여부를 확인한다.
2. 결측을 학습 입력과 정답에서 구분한다. 목표 결측을 입력 결측처럼 대치하지 않는다.
3. CSV를 수정했다면 기존 SHA-256과 결과는 재현 기준으로 더 이상 일치하지 않는다.
4. 관측 범위 밖 수치를 즉시 잘못된 값으로 삭제하지 말고, 정의·수집 조건·모델 입력 범위를 확인한다.
5. 전처리 통계와 모델 선택은 훈련·검증 범위에서 수행하고 최종 평가 자료를 분리한다.

# 6.13 데이터 사전과 입력 검증

이 값은 배포한 고정 CSV에서 직접 계산했다. 최소·최대는 이 파일의 관측 범위이며 모델의 허용 범위나 모집단의 한계가 아니다. 결측 수는 NaN 기준이다.

## housing.csv

900행. 전체 열 기준 완전 중복 0행. 기존 GitHub 06_Regression/housing_regression.csv를 열 이름만 바꾼 자료. 실측·합성 여부와 원 단위는 미확인.

- `area`: 원 저장소의 주택 면적 관련 특성. float64; 결측 0개; 고유값 860개; 범위 25~188.79, 평균 94.7211.
- `rooms`: 원 저장소의 방 수 관련 특성. int64; 결측 0개; 고유값 6개; 범위 1~6, 평균 3.45111.
- `age`: 원 저장소의 건축 연수 관련 특성. int64; 결측 0개; 고유값 50개; 범위 0~49, 평균 25.3944.
- `distance`: 원 저장소의 거리 관련 특성. float64; 결측 0개; 고유값 749개; 범위 0.2~25, 평균 12.3255.
- `school_score`: 원 저장소의 학군 점수 관련 특성. float64; 결측 0개; 고유값 836개; 범위 40.01~99.98, 평균 69.1176.
- `price`: 원 저장소의 주택 가격 목표. 금액 단위 미확인. int64; 결측 0개; 고유값 897개; 범위 11576~485385, 평균 261573.
## nonlinear.csv

100행. 전체 열 기준 완전 중복 0행. 난수 시드 42의 교육용 합성 비선형 회귀. 실제 측정값 아님.

- `x`: 무차원 독립 입력. float64; 결측 0개; 고유값 100개; 범위 -2.87033~2.95425, 평균 0.00739662.
- `y`: 생성식으로 만든 연속형 목표. float64; 결측 0개; 고유값 100개; 범위 -1.26959~1.3928, 평균 -0.0479303.

## 재실행 전 검사

1. 열 이름과 순서, 목표 열의 제외 여부를 확인한다.
2. 결측을 학습 입력과 정답에서 구분한다. 목표 결측을 입력 결측처럼 대치하지 않는다.
3. CSV를 수정했다면 기존 SHA-256과 결과는 재현 기준으로 더 이상 일치하지 않는다.
4. 관측 범위 밖 수치를 즉시 잘못된 값으로 삭제하지 말고, 정의·수집 조건·모델 입력 범위를 확인한다.
5. 전처리 통계와 모델 선택은 훈련·검증 범위에서 수행하고 최종 평가 자료를 분리한다.
